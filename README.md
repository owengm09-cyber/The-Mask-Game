# The Mask Game

Roblox game managed with [Rojo](https://rojo.space).

## Setup
1. Install tools: `rokit install` (or install Rojo 7.4.x and the Studio plugin manually).
2. In this folder run `rojo serve`.
3. In Roblox Studio, open the Rojo plugin and click **Connect**.

## Layout
| Path | Roblox location |
| --- | --- |
| `src/shared` | `ReplicatedStorage.Shared` |
| `src/server` | `ServerScriptService.Server` |
| `src/client` | `StarterPlayer.StarterPlayerScripts.Client` |
